# Novelty Search Protocol

## Query Families

For each core claim, search:

1. exact names, acronyms, and distinctive phrases;
2. synonyms and older terminology;
3. task + mechanism;
4. task + setting or dataset;
5. mechanism + claimed effect;
6. the closest paper's references and citing papers;
7. recent venue proceedings and preprints.

Use the current date. Do not hard-code conference years that will become stale.

## Evidence Row

Record for every serious neighbor:

- stable title, authors, year/date, venue or source, DOI/arXiv/official locator;
- publication state and first-public date when known;
- overlap in task, mechanism, setting, evaluation, and claimed finding;
- decisive difference and the exact source passage or section supporting it;
- confidence and unresolved ambiguity.

## Report Shape

1. Proposed contribution
2. Core claims
3. Search scope and date
4. Closest prior-work table
5. Claim-level novelty assessment
6. Concurrent-work risk
7. Defensible delta and suggested positioning
8. Overall recommendation and remaining search gaps
