# Paper Plan Pattern

Use this pattern when `drafts/outline.md` needs to function as a real paper plan instead of a loose section list.

## Recommended Sections Inside `drafts/outline.md`

1. Core claim
2. Fallback weaker claim
3. Story spine
4. Claim-evidence matrix
5. Hero figure or table
6. Section plan
7. Page or emphasis budget
8. Risks and unsupported side claims

## Claim-Evidence Matrix

For each top-level claim, record:

- claim text
- strongest supporting figure or table
- supporting run IDs or result rows
- confidence level
- what would falsify or weaken the claim

Do not let a claim stay in the main arc if no concrete evidence row owns it.

## Hero Figure Rule

Choose one figure or table that would still carry the paper if the reader only remembered a single empirical artifact.

The hero artifact should:

- express the main result cleanly
- dominate the abstract and intro promise
- survive venue compression better than secondary ablations

If no candidate hero figure exists, the story is probably still too weak or too diffuse.

## Section And Page Budget

Set rough expectations for:

- number of sections
- which section carries the main evidence
- which section can be shortened or demoted if page pressure rises
- which figures are essential versus nice-to-have

Use the budget to force early tradeoffs instead of discovering them at submission time.
